# SMCC Practice Studio บน Hostinger

เว็บติวดนตรีฟรี ใช้ PHP 8.2 ขึ้นไป พร้อมส่วนขยาย PDO MySQL, mbstring, OpenSSL และ session ใช้ฐานข้อมูล MySQL หรือ MariaDB และกล่องอีเมล SMTP สำหรับส่งลิงก์ยืนยันบัญชี ผู้เรียนสมัครด้วยอีเมลและรหัสผ่าน จากนั้นเปิดลิงก์ยืนยันก่อนเข้าบทเรียนและแบบฝึก ระบบบันทึกความคืบหน้าลงฐานข้อมูลหลังเข้าสู่ระบบ

## ติดตั้ง

1. เพิ่มเว็บไซต์แบบ **Custom PHP/HTML** ใน hPanel เลือกโดเมน และเปิด SSL กับ Force HTTPS จากนั้นเลือก PHP 8.2 ขึ้นไปใน PHP Configuration
2. สร้างฐานข้อมูลและผู้ใช้ MySQL ใน hPanel ใช้ phpMyAdmin เปิดฐานข้อมูลที่เพิ่งสร้างและนำเข้า `schema.sql` หนึ่งครั้ง
3. แตก ZIP แล้วอัปโหลดเนื้อหา `public_html` รวมถึง `.htaccess` ไปยัง `domains/<โดเมน>/public_html` และอัปโหลดทั้งโฟลเดอร์ `smcc-private` ไว้ที่ `domains/<โดเมน>/smcc-private`
4. สร้างกล่องอีเมลสำหรับส่งลิงก์ยืนยันใน hPanel หรือใช้ผู้ให้บริการ SMTP ที่มีอยู่ คัดลอก `smcc-config.example.php` เป็น `smcc-config.php` ระบุ HTTPS URL จริง ข้อมูลฐานข้อมูล และข้อมูล SMTP แล้วอัปโหลดไปที่ `domains/<โดเมน>/smcc-config.php` ซึ่งอยู่ระดับเดียวกับโฟลเดอร์ `public_html`
5. เปิดเว็บผ่าน HTTPS คลิก **สมัครฟรี** แล้วทดลองเปิดลิงก์จากอีเมล กรอกรหัสผ่านเพื่อยืนยัน จากนั้นทำโจทย์หนึ่งข้อ ออกจากระบบ และเข้าสู่ระบบอีกครั้งเพื่อตรวจคะแนน

ใช้ File Manager แบบ **Access all files** หรือ SFTP สำหรับอัปโหลด `smcc-private` และไฟล์ตั้งค่าที่อยู่นอกโฟลเดอร์เว็บ วางเฉพาะไฟล์จาก `public_html` ในพื้นที่เว็บเพื่อให้ระบบตรวจสิทธิ์ก่อนส่งไฟล์บทเรียน ไฟล์ SQL และคู่มือนี้มีไว้สำหรับติดตั้ง

หากใช้บริการส่งอีเมล PHP ของ Hostinger ให้ตั้ง `'transport' => 'mail'` และระบุ `'from'` ของโดเมนในส่วน `smtp` ของ `smcc-config.php` เมื่อต้องการเปลี่ยนเป็น SMTP ให้ตั้ง `'transport' => 'smtp'` และใส่ข้อมูลบัญชี SMTP ในไฟล์เดิม

รุ่น Hostinger ใช้ฐานข้อมูลแยกจาก ChatGPT Sites ผู้เรียนสร้างบัญชีบนโดเมนใหม่และใช้ความคืบหน้าที่บันทึกบนโดเมนนั้น

## สร้างไฟล์ติดตั้งใหม่จากซอร์ส

จากไดเรกทอรี `app` รันด้วย Python 3

```text
python hostinger/package.py ../SMCC-Hostinger.zip
```
