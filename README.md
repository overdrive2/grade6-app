# SMCC Practice Studio

เว็บติวดนตรีฟรี อิงเกณฑ์เตรียมสอบ SMCC ระดับกลาง เกรด 6 มีบทเรียนพื้นฐานและบทเตรียมสอบ แบบฝึกโต้ตอบ Three.js และเสียงแกรนด์เปียโน

## ติดตั้งบน Hostinger

ใช้ Custom PHP/HTML, PHP 8.2 ขึ้นไป, MySQL หรือ MariaDB และ SMTP สำหรับส่งลิงก์ยืนยันบัญชี ผู้เรียนต้องยืนยันอีเมลก่อนเข้าเรียน ระบบบันทึกความคืบหน้าลงฐานข้อมูล

อ่าน [คู่มือติดตั้ง](hostinger/README.md) และสร้างชุด ZIP จากรากของ repository ด้วย Python 3

```text
python hostinger/package.py ../SMCC-Hostinger.zip
```

อัปเดตโดยใช้ ZIP จากเวอร์ชันใหม่และเก็บ `smcc-config.php` กับฐานข้อมูลเดิมไว้ สำหรับรุ่นที่แก้โครงสร้างฐานข้อมูล ให้ใช้ migration ของรุ่นนั้น ส่วน `hostinger/schema.sql` ใช้กับการติดตั้งใหม่

## โครงสร้างโค้ด

- `dist/` เป็นซอร์สหน้าเรียนที่ใช้ร่วมกันระหว่างรุ่น Hostinger และ Sites
- `hostinger/` เป็นหน้าเริ่มต้น ระบบบัญชี PHP สคริปต์สำหรับสร้าง ZIP และสคีมาติดตั้ง
- `worker.mjs` และ `drizzle/` ใช้สำหรับรุ่น Sites
